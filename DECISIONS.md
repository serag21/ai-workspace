## Operational decision boundaries

**Automatically allowed within the dev branch:** inspect existing source/docs, deterministic tests, local CPU-only analysis, bounded coding/refactors/bug fixes, create and modify synthetic fixtures, make safe commits/pushes to the isolated branch, update state, and suggest backlog reorder.

**Needs explicit owner approval:** any real personal provider login/automation, local agent resume against a real/active session, sending real handoff contents, major architecture pivot, public distribution, account/secret usage, spend/new subscriptions, destructive changes and unattended GPU worker activation.

**Never allowed as a workaround:** bypass OAuth restrictions, copy Chrome session cookies, disable GitHub secret scanning, recreate a flashing Windows supervisor, kill unrelated GPU jobs, unilaterally launch the shared arbiter or use private content in public diagnostics.
